# CARROM V1

Jeu de carrom numérique conçu par Twagirumukiza.

## Mise en ligne sur GitHub Pages

1. Envoyez tous les fichiers de ce dossier à la racine du dépôt `CARROM`.
2. Dans le dépôt, ouvrez **Settings → Pages**.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche **main**, le dossier **/(root)**, puis **Save**.

Le jeu fonctionne sans installation, sans compilation et sans serveur.

## Fonctionnalités

- Deux joueurs sur le même appareil
- Mode contre l’intelligence artificielle
- Collisions, rebonds, frottements et poches
- Commandes tactiles et souris
- Scores, sons et règles
- Sauvegarde automatique de la partie contre F5
- Affichage responsive pour téléphone, tablette et ordinateur
